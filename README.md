# Code Lift

Landing page institucional da **Code Lift**, empresa fictícia focada em soluções para web, desenvolvida em HTML, CSS e JavaScript puros.

## Sobre

O site apresenta a proposta de valor da empresa, um resumo do processo de trabalho (desenvolvimento, design, otimização e responsividade) e um botão de contato direto via WhatsApp.

## Tecnologias

- HTML5
- CSS3 (com media queries para responsividade)
- JavaScript

## Como rodar

Não há build ou dependências. Basta abrir o arquivo `index.html` no navegador ou servir a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Estrutura

```
index.html      # Estrutura da página
style.css       # Estilos principais
medias.css      # Responsividade (media queries)
scripts.js      # Interações/animações
images/         # Assets visuais e ícones
```
